# Сильные сухожилия и гибкость

Офлайн-приложение (PWA) о статических упражнениях для сухожилий и гибкости: восемь глав с исследованиями и режимами, программа на 12 недель, таймер удержаний и дневник занятий. Записи дневника хранятся в `localStorage` на устройстве.

## Установка на телефон

Откройте сайт в браузере телефона. На главной появится карточка «Установите на телефон», а в шапке кнопка «Установить».

- **Android (Chrome, Edge, Samsung Internet).** Кнопка вызывает системное окно установки. Если браузер его не дал, приложение покажет, где в меню пункт «Добавить на главный экран».
- **iPhone и iPad.** Своего окна установки в iOS нет, поэтому приложение показывает шаги: «Поделиться» → «На экран „Домой“» → «Добавить».

После установки иконка «Сухожилия» появляется на главном экране, приложение открывается в отдельном окне и работает без интернета. Если долго нажать на иконку в Android, появятся ярлыки «Таймер» и «Дневник».

Установка работает только по HTTPS, поэтому приложение нужно опубликовать, например на GitHub Pages.

## Публикация на GitHub Pages

1. Settings → Pages → Build and deployment → Source: **Deploy from a branch**.
2. Выберите ветку с приложением и папку `/ (root)`, нажмите Save.
3. Через минуту сайт откроется по адресу `https://<пользователь>.github.io/tendon_conditioning/`.

Файл `.nojekyll` отключает обработку Jekyll, и файлы раздаются как есть.

## Структура

- `index.html`: приложение целиком (разметка, стили, скрипт).
- `manifest.webmanifest`: название, иконки, ярлыки «Таймер» и «Дневник», скриншоты для окна установки в Android.
- `icons/`: иконки приложения и ярлыков. `screenshots/`: снимки экранов для окна установки.
- `tools/figures.py`: рисует картинки к упражнениям в главах 5 и 8 и вписывает их в `index.html`. Человек собран как манекен с пропорциями взрослого: у бёдер, голеней, рук и корпуса свой профиль толщины, есть голова в профиль, кисти и стопы. Позы заданы углами суставов и точками опоры, рабочая мышца закрашивается акцентным цветом, цвета берутся из темы. После правки поз запустите `python3 tools/figures.py`.
- `sw.js`: сервис-воркер. Кэширует оболочку и шрифты, чтобы приложение открывалось без сети.
- `standalone/index.html`: то же приложение одним файлом, с иконками и манифестом внутри. Его можно открыть прямо с диска или переслать. Собирается командой `python3 tools/build_standalone.py`.

## Локальный запуск

Сервис-воркер не работает с `file://`, поэтому нужен локальный сервер:

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

После изменения `index.html` (в том числе картинок) пересоберите `standalone/index.html` и поднимите версию `CACHE` в `sw.js`, чтобы у пользователей обновился кэш.
